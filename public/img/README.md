# Logo Files

Silakan upload 2 logo ke folder ini:

1. **logo-univ.png** - Logo Universitas Pasir Pengaraian
2. **logo-pkkmb.png** - Logo PKKMB 2026

## Spesifikasi Rekomendasi:
- Format: PNG (dengan background transparan lebih baik)
- Ukuran: 500x500px minimum
- File size: < 500KB

## Lokasi Penggunaan:
- Landing page (index.html) - hero section
- Login page
- Register page  
- Admin dashboard - navbar
- Mahasiswa dashboard - navbar

## Catatan:
Jika logo belum diupload, sistem akan menampilkan fallback icon emoji (🎓 dan 📚)
