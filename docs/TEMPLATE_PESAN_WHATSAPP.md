## ✅ TEMPLATE 1: Registrasi Bertahap (RECOMMENDED)

### Pesan Awal (Kirim H-2 atau H-1)

```
📢 PENGUMUMAN PENTING - PKKMB 2026

Halo Maba! 👋

Untuk absensi PKKMB nanti, kalian wajib daftar akun terlebih dahulu di sistem online kami.

⚠️ Agar sistem tidak overload, pendaftaran akan dilakukan BERTAHAP per fakultas.

🕐 JADWAL REGISTRASI:
━━━━━━━━━━━━━━━━━━━
📅 SENIN, XX BULAN:
• Fakultas Teknik: 14:00 - 16:00
• Fakultas Ekonomi: 16:00 - 18:00

📅 SELASA, XX BULAN:
• Fakultas Keguruan: 09:00 - 11:00
• Fakultas Pertanian: 11:00 - 13:00
• Fakultas Perikanan: 14:00 - 16:00

🌐 Link Registrasi (SIMPAN LINK INI):
https://absensi-pkkmb-2026.netlify.app/register.html

📝 YANG PERLU DISIAPKAN:
✓ Email aktif (gmail/yahoo/dll)
✓ NIM
✓ Nama lengkap sesuai ijazah
✓ Tahu fakultas & prodi kalian

⚠️ ATURAN PENTING:
1. Daftar HANYA di jam fakultas kalian
2. Tunggu 10-15 detik setelah klik "Daftar"
3. JANGAN spam/klik berkali-kali
4. JANGAN refresh halaman
5. Kalau error, tunggu 1 menit lalu coba lagi

💡 TIPS:
• Gunakan WiFi/koneksi stabil
• Buat password mudah diingat (min 6 karakter)
• CATAT email & password kalian baik-baik!

Link ini akan diingatkan lagi sesuai jadwal fakultas masing-masing.

Mohon kerjasamanya! 🙏

#PKKMB2026 #UniversitasPasirPengaraian
```

## 📝 NOTES

**Best Practice:**
1. Kirim pesan pertama H-2 atau H-1
2. Reminder 5-10 menit sebelum slot
3. Update progress setiap slot selesai
4. Pin pesan penting di grup
5. Siapkan FAQ untuk copy-paste cepat

**Jangan:**
- ❌ Kirim link tanpa instruksi jelas
- ❌ Lupa reminder sebelum slot
- ❌ Tidak ada team standby saat registrasi
- ❌ Tidak prepare backup plan

**Kalau sistem crash:**
- Segera kirim template emergency
- Aktifkan Google Form backup
- Tenangkan mahasiswa
- Update berkala tentang progress
