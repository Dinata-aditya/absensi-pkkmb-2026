## ⚙️ Cara Admin Mengaktifkan Sertifikat

1. Login ke **Admin Dashboard**
2. Buka tab **Pengaturan Sistem**
3. Cari setting **"Aktifkan Sertifikat"**
4. Toggle ke **ON** (hijau)
5. Klik **Simpan Perubahan**

Setelah diaktifkan:
- Mahasiswa yang memenuhi syarat (4-5 kehadiran) akan melihat tombol **"Download Sertifikat"**
- Mahasiswa yang tidak memenuhi syarat akan melihat pesan **"Sertifikat Tidak Tersedia"**

## 📝 FAQ

### **Q: Kalau saya hadir 4 dari 5, dapat sertifikat?**
A: **Ya**, Anda dapat sertifikat. Syarat minimal adalah 3 kehadiran.

### **Q: Kalau saya hadir 3 dari 5, dapat sertifikat?**
A: **Ya**, Anda dapat sertifikat. 3 kehadiran adalah batas minimal.

### **Q: Kalau saya hadir 2 dari 5, dapat sertifikat?**
A: **Tidak**, Anda tidak dapat sertifikat. Minimal 3 kehadiran.

### **Q: Boleh tidak hadir di hari ketiga?**
A: **Boleh**, asal total kehadiran Anda minimal 3 dari 5 sesi.

### **Q: Boleh tidak hadir 2 hari penuh?**
A: **Tidak**, karena minimal harus hadir 3 sesi. Kalau tidak hadir 2 hari penuh (4 sesi), maksimal Anda cuma hadir 1 sesi.

### **Q: Kalau hadir 5 dari 5, dapat bonus?**
A: Tidak ada bonus khusus, tapi Anda mendapat sertifikat dengan catatan kehadiran sempurna.

### **Q: Saya sudah hadir 4 kali, tapi tombol download belum muncul?**
A: Kemungkinan panitia belum mengaktifkan fitur sertifikat. Tunggu pengumuman dari panitia.

### **Q: Kalau saya terlambat scan 1 sesi, apakah tetap dihitung hadir?**
A: Tergantung aturan sesi. Kalau sesi sudah ditutup admin, Anda akan tercatat ALPHA.

### **Q: Saya scan tapi tidak tercatat, bagaimana?**
A: Segera lapor ke panitia dengan screenshot. Admin bisa input manual kehadiran Anda.

### **Q: Apakah sertifikat bisa diedit setelah download?**
A: Sertifikat dalam format PNG. Kalau ada kesalahan data (nama/NIM/prodi), hubungi admin untuk perbaiki di database, lalu download ulang.

## 📌 Catatan Penting

1. **Sertifikat hanya diterbitkan 1 kali**
   - Pastikan data Anda (nama, NIM, prodi) sudah benar sebelum download
   - Kalau ada kesalahan, hubungi admin untuk perbaiki

2. **Format sertifikat: PNG (gambar)**
   - Resolusi tinggi (5999 x 4242 px)
   - Bisa langsung dicetak atau disimpan digital

3. **Nama di sertifikat:**
   - Sesuai data yang Anda daftarkan saat registrasi
   - HURUF KAPITAL semua
   - Font: Times New Roman (formal)

4. **Nomor sertifikat:**
   - Format: XXX/PKKMB/09.2026
   - XXX = 3 digit terakhir NIM Anda
   - Contoh: NIM 2536062 → No. 062/PKKMB/09.2026

## 🔄 Riwayat Perubahan Syarat

### **Sebelumnya:**
- Syarat: Hadir **minimal 2 sesi di SETIAP hari**
- Artinya: Harus hadir 2x di Hari 1, 2x di Hari 2, dan 1x di Hari 3
- Total minimal: 5 dari 5 sesi (tidak boleh miss sama sekali)

### **Sekarang (Perubahan Terbaru):**
- Syarat: Hadir **minimal 3 dari 5 total sesi (60%)**
- Artinya: Boleh miss 2 sesi, tidak peduli hari mana
- Sangat fleksibel untuk mahasiswa

**Alasan perubahan:**
- Lebih realistis untuk mahasiswa
- Toleransi 2 sesi untuk kondisi darurat (sakit, urusan keluarga, dll)
- Tetap menjaga standar kehadiran minimal 60%
- Lebih banyak mahasiswa yang dapat sertifikat
